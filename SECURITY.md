# Security policy

**Pre-alpha:** no released version, guaranteed support period, or bug-bounty program.

Do not publish secrets or exploit details in Issues, PRs, or Discussions. Use **Security -> Report a vulnerability** when GitHub's private vulnerability reporting is enabled. Otherwise request a private reporting route in a public issue **without disclosure details**.

Coding-agent instructions, model output and issues are untrusted inputs. They do not authorize production credentials, host execution, merge, deploy, or privilege escalation.

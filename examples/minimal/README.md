# Minimal repository example

Copy the example `AGENTS.md` and hidden `.kovan/` directory into a test repository and tailor the role names and scope. The example roles are illustrative, not a registry or production permission configuration.

Use an existing runtime to start one designated CoS and approved Lead seats. Read the shared rules and each assigned role from a trusted revision, plus actual ownership and task context. Start subagents through the Lead's native delegation mechanism.

No automated issue dispatch, runtime configuration, credentials or deployments are included. Validate loading and lifecycle behavior before enabling unattended work. See [the draft spec](../../SPEC.md).

# Contributing

Kovan is pre-alpha. The community implementation has not been published yet.

- Propose focused issues and small PRs when issue intake is enabled.
- Include deterministic tests and precise evidence for any implementation.
- Do not claim a docs/source smoke check proves an end-to-end workflow.
- Prefer upstream reuse over creating schedulers, agent harnesses, CI or GitOps.
- Never contribute secrets, personal network endpoints, private deployment state or customer data.
- PR CI must use GitHub-hosted runners and read-only permissions; untrusted forks must never execute on persistent personal machines.

Contributions are submitted under the repository's Apache-2.0 license; there is no contributor license agreement at this stage.
